# Release checklist

- Run frontend lint, build, and browser verification.
- Run Studio typecheck, schema extraction, TypeGen, and build.
- Check desktop, tablet, and mobile filters; routes; refresh/back; EN/IT; keyboard focus; and reduced motion.
- Confirm new CMS project behavior, favicon/theme color, project metadata, sitemap output, and malformed-project resilience.
- Audit production image sizes and Core Web Vitals.
- Verify font licensing and never deploy secrets or mutate CMS content through validation.
